# Elite Realty — Brand Reference

**Updated:** December 25, 2024  
**Source:** Alexandra's approved design direction

---

## Logo

The ER monogram combines an elegant "E" and "R" in a modern serif style.
- **Primary:** White logo on dark background
- **Alternate:** Dark logo on light background (for light sections if needed)
- Text "ELITE REALTY" below in spaced uppercase letters

---

## Color Scheme (Dark Theme)

Alexandra has chosen a **dark, sophisticated aesthetic** that matches her logo and brand positioning.

### Primary Colors

| Name | Hex | Usage |
|------|-----|-------|
| **Black** | `#0a0a0a` | Primary background |
| **Dark Gray** | `#1a1a1a` | Card backgrounds, sections |
| **Charcoal** | `#2d2d2d` | Borders, dividers |
| **White** | `#ffffff` | Primary text, logo |
| **Light Gray** | `#a0a0a0` | Secondary text, captions |
| **Gold** | `#d4af37` | Accents, CTAs (optional) |

### Theme Philosophy
- **Sophisticated** — Dark backgrounds convey luxury
- **High contrast** — White text on black for readability
- **Photo-forward** — Dark backgrounds make property images pop
- **Minimal** — Clean typography, generous whitespace

## Typography Observations

| Element | Style |
|---------|-------|
| Logo text | Uppercase, wide letter-spacing |
| Navigation | Regular weight, clean sans-serif |
| Headings | Serif font (like Playfair Display) |
| Body | Sans-serif (like Inter), light weight |
| Location labels | Sans-serif, regular weight |

---

## Image Treatment

- **Full-bleed** images that extend edge to edge
- **Slight dark overlay** on images with text
- **High quality** aerial/architectural photography
- **Dramatic compositions** — ocean views, skylines
